## 结论和处理

同学完成了新环境建站和基础读取迁移，有可用演示成果。它仍是独立最小实现，不能替代已经编写的完整修复版。原代码与记录保留在 history 中，避免混淆部署入口。

用户要求长期运行，因此生产采用 Python 3.12 + Waitress/Flask 容器，部署于正式 Linux 云服务器。Python 3.12 于 2023 年正式发布，计划安全支持到 2028-10；Python 3.10 已于 2026-10-01 结束维护。官方还明确不推荐将 `http.server` 用于生产服务。依据及完整方案见 [生产部署说明](../../deploy/production/README.md)。

配置中已记录新演示地址，但保持 source=local；该地址的标准前缀仍 404，正式切换必须等修复版生产部署和验收完成。当前没有升级或删除任何云端函数。
