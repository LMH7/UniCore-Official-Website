## 一句话

用**腾讯云函数**（Serverless，不租服务器）提供两个只读接口，前端改一行地址就能把数据来源从本地文件切成接口。

## 线上地址

```
https://1529293111-996nrvu444.ap-chengdu.tencentscf.com
```

| 接口 | 作用 | 返回 |
| --- | --- | --- |
| `GET /products` | 三款产品 | `{"data": [ ... ]}` |
| `GET /site-content` | 团队、方案、资源、FAQ、联系方式 | `{"data": { ... }}` |
| `GET /` | 健康检查 | `{"data": {"ok": true, "hint": "..."}}` |

字段结构见仓库 `docs/api-examples/products.json` 与 `site-content.json`，与前端校验层完全对齐。

## 做了什么

- 只读，不需要登录，访客直接读
- 跨域头 `Access-Control-Allow-Origin: *`（稳定后可收窄到 `https://lmh7.github.io`）
- 缓存 `Cache-Control: public, max-age=60`
- 图片、Logo、二维码返回**绝对 HTTPS 地址**，所以前端部署在别的域名也能加载
- 中文 UTF-8，无乱码
- 数据从仓库的 `docs/api-examples/` 生成，不是手抄，改内容重新生成即可

## 部署步骤（实际走过的路）

1. 腾讯云控制台 → **云函数 SCF** → 函数服务 → **新建**
2. 选 **模板创建** → **Flask 框架模板** → 下一步
3. 函数名称 `inexapi`，地域按就近选（本项目在成都）
4. 展开 **函数URL配置**，**勾选「公网访问」**（不勾就没有公网地址）
5. 勾选协议 → 完成
6. 进「函数代码」，编辑 `src/app.py`，用本目录的 `app.py` 全文替换
7. `Ctrl + S` 保存 → 在编辑器底部把 **自动部署** 打开（或点部署）
8. 到「函数 URL」复制地址，贴进浏览器测试

> 模板自带的 Flask 依赖已内置在 `src/` 里，不用自己装。

## 前端怎么切

改 `site/assets/js/data-service.js` 开头：

```js
window.DATA_CONFIG = Object.freeze({
  source: "api",
  apiBase: "https://1529293111-996nrvu444.ap-chengdu.tencentscf.com/",
  timeoutMs: 5000,
});
```

改完刷新即可。**不切也能正常上线**，默认 `source: "local"` 读本地文件。

## 出问题怎么退

- 把 `source` 改回 `"local"`，恢复原状
- 函数挂了、超时、返回格式不对，前端会自动回退本地快照并提示，不会白屏

## 注意事项

1. **阿里云那条路没走通**：函数能执行，但默认公网域名没下发，报 `Subdomain ... is invalid` / `DomainNameNotFound`，所以改用腾讯云。若以后在阿里云复现，优先绑定已备案的自定义域名。
2. **不要买任何套餐**，用免费额度就够，这种访问量用不完。
3. 函数代码改动后必须确认状态为**已部署**，否则线上还是旧代码。
4. 不要把接口测试数据提交到 `site/` 下（会变成第二份内容源）。
5. 这个函数目前由 B 的个人账号托管。若团队要长期使用，应迁到团队账号，并记录账号归属与到期时间。
