# 接口说明（给做云函数的同学）

> **状态更新（2026-11-10）**：这两个接口已由 B 在腾讯云函数上实现并实测通过，实现说明见 `docs/function/README.md`。
> 本文继续作为**契约文档**使用：谁接手后端，照这里的要求实现即可，前端不用改。

联核智域官网的前端已经写好，**只等两个接口**。做完这两个 GET，网站就能接上后端，前端代码不用改。

## 一、两个地址

```
GET /api/v1/products
GET /api/v1/site-content
```

云函数在阿里云/腾讯云上，最终会得到一个 HTTPS 地址，例如：

```
https://xxxx.cn-hangzhou.fcapp.run/api/v1/
```

前端只要改这一行就能切过去（`site/assets/js/data-service.js` 开头）：

```js
apiBase: "https://你们云函数的地址/api/v1/",
```

> 注意结尾那个 `/` 不能少。

## 二、返回什么

统一格式，外面包一层 `data`：

```json
{ "data": [ ... ] }
```

- `products` 的 `data` 是**数组**，元素结构见 `docs/api-examples/products.json`
- `site-content` 的 `data` 是**对象**，结构见 `docs/api-examples/site-content.json`

这两个文件就是"标准答案"，照着返回即可。**不要改字段名**，前端的校验层会拒绝。

## 三、必须满足的五条

1. **HTTPS**。前端强制要求，`http://` 会直接拒绝（`127.0.0.1` 除外，方便本地调试）。
2. **CORS 响应头**。至少要有：
   ```
   Access-Control-Allow-Origin: *
   ```
   先用 `*` 图省事，稳定后再收窄到 `https://lmh7.github.io`。
3. **`Content-Type: application/json; charset=utf-8`**，中文不能乱码。
4. **只返回允许公开的内容**。草稿、未审核产品、内部资料由服务端过滤，别指望前端藏。
5. **图片地址用完整 HTTPS 地址**，例如 `https://你的域名/images/nex-500.webp`，不能写相对路径。

## 四、不要做的事

- 不要给这两个 GET 加登录校验（访客要能直接看）
- 不要返回 HTML 页面，只能是 JSON
- 不要把 CSS/JS 也塞进云函数（前端还在 GitHub Pages）
- 不要用 302 跳转糊弄路径

## 五、怎么算做完

在浏览器里打开下面两个地址，各看到一段 JSON：

```
https://你们的地址/api/v1/products
https://你们的地址/api/v1/site-content
```

然后告诉 B（我）地址，我在本地把 `apiBase` 改过去刷新，看到首页产品变成接口里的内容，就算联调通过。

## 六、本地已经验证过的事

用本地假接口（同样的路径、同样的格式）跑通过一次：

- 前端能正常读取并渲染卡片
- 改接口里的文字，页面刷新就跟着变，前端代码没动
- 接口挂掉时，页面自动退回本地数据，不会白屏

所以只要云函数按上面的格式返回，一次就能接上。
