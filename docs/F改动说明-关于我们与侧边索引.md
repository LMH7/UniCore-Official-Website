## 三、侧边栏目索引组件（page-index）

由关于页原有的 `about-index` 泛化而来，现为全站通用组件：

### 结构

```html
<div class="page-layout">
  <aside class="page-index" aria-label="栏目索引">
    <span class="page-index-title">本页内容</span>
    <nav>
      <a href="#section-id"><span class="page-index-num">01</span>条目名</a>
    </nav>
  </aside>
  <div class="page-layout-main">…页面主体…</div>
</div>
```

### 样式

- 桌面端：白色圆角面板（与顶部主导航同风格：白底 + 细分隔线边框 + 轻投影），宽 248px，与主内容间距 64px。
- 条目默认灰色文字（同导航 #5b6775），悬停变浅蓝底 + 蓝字；当前板块为蓝字 + 浅蓝底 + 蓝色左边条指示（即顶部导航选中蓝线的竖排版）。
- 垂直位置：`position: fixed`，由 JS 动态计算 `top`（基准略低于屏幕正中），滚动/缩放时实时避让页面顶部深色横幅、固定导航与页脚——顶端始终不低于横幅下边缘 16px，底端不压页脚；水平方向跟随页面容器自动对齐。
- 面板高度自适应可用垂直区间（横幅下方 ↔ 页脚上方），空间不足时在面板内部滚动，不会整体顶出屏幕。
- 移动端（≤991px）：回退为内容顶部横向滚动条（sticky），毛玻璃白底，保持可用性。
- 每个侧边栏底部统一放置品牌卡（深色底 + iNEX 标识）；关于我们页在品牌卡下方的白色区域另有两架手绘风格无人机插画（带浮动动画，投影按白底加重），移动端横条模式下品牌卡与无人机自动隐藏。

### 交互（interactions.js）

- 索引高亮基于滚动位置计算（判定线 + 接近底部点亮末条），替代早期 IntersectionObserver 方案，修复"滚到底再上滚时高亮卡住"的问题；按每个 `.page-index` 自身链接 hash 自动匹配目标板块，新增页面只需照结构写 HTML，无需改脚本。
- 桌面端 fixed 模式下由 `placeSidebar()` 统一负责垂直定位与限高（见上）；移动端 sticky 布局自动跳过这些逻辑。
- 各锚点已设置 `scroll-margin-top`，跳转后标题不被固定导航遮挡。
